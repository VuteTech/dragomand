# Artwork

The official Dragomand artwork:

- `dragomand-logo.svg`: the wordmark, used by the README and the
  website header.
- `dragomand-icon.svg`: the square icon, installed as the hicolor icon
  `dev.l10n_bg.dragomand` and used as the website favicon.

## Credits

The wordmark lettering is drawn as SVG paths; no font is embedded or
distributed. Its letterforms were inspired by Comfortaa SemiBold, the
rounded geometric typeface by Johan Aakerlund (published under the SIL
Open Font License 1.1), without using the font directly.
